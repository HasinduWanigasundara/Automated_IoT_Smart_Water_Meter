# 💧 Automated IoT Smart Water Meter

**Project for EN2160 - Electronic Design Realization** *Department of Electronic and Telecommunication Engineering, University of Moratuwa*

[cite_start]An ultra-low-power, end-to-end IoT smart water metering system designed to tackle Sri Lanka’s Non-Revenue Water (NRW) challenges[cite: 208, 209]. [cite_start]By replacing conventional manual metering, this system enables real-time water consumption monitoring, automated billing, and early leak detection[cite: 241, 242, 244].

## 💡 System Overview

[cite_start]The system integrates embedded hardware, GSM communication, and cloud-based data management to create a scalable IoT platform[cite: 230]. 

[cite_start]A Hall-effect sensor detects electrical pulses generated by a rotor-mounted permanent magnet as water flows[cite: 232, 233]. [cite_start]An STM32L0 microcontroller processes these pulses to calculate the instantaneous flow rate and cumulative water volume[cite: 234]. [cite_start]The data is then transmitted via a SIM800L GSM module using HTTP POST requests to a centralized Supabase cloud database[cite: 235, 236, 237].

## 🚀 Key Features

* **Ultra-Low Power Architecture:** Powered by a 19,000 mAh Li-SOCl2 primary battery. [cite_start]By utilizing the STM32L0's sleep states and duty-cycling the GSM module, the system is designed for a 10+ year operational lifespan[cite: 243, 259, 262].
* [cite_start]**Real-Time GSM Telemetry:** Standalone operation using quad-band GSM/GPRS; does not rely on local Wi-Fi infrastructure[cite: 236, 250].
* [cite_start]**Automated NRW Detection:** Continuous flow monitoring identifies abnormal consumption patterns and potential leaks[cite: 244].
* **Dual Web Dashboards:**
  * [cite_start]**WaterboardOS:** A centralized administrative portal for utilities to monitor system-wide analytics, revenue, and active clients[cite: 301, 303].
  * [cite_start]**AquaSync:** A consumer-facing web application for live bill estimation, historical usage tracking, and leak notifications[cite: 301, 311, 313, 314].

## ⚙️ Hardware Specifications

[cite_start]The custom 2-layer FR-4 PCB was designed using Altium Designer[cite: 263, 296].

* [cite_start]**Microcontroller:** STM32L071CBT6 (32-bit ARM Cortex-M0+ @ 32 MHz)[cite: 249, 275].
* [cite_start]**Communication:** SIM800L GSM/GPRS Module (Power toggled via AO3401A P-channel MOSFET)[cite: 250, 285].
* [cite_start]**Power Subsystem:** 3.6V Li-SOCl2 Battery regulating to a 3.3V LDO (XC6206) for the MCU and a 4V Buck-Boost Converter (TPS61023DRLR) for the GSM module[cite: 251, 268, 269, 270].
* [cite_start]**Sensors & Peripherals:** Hall-effect flow sensor inputs (TIM2), I2C OLED display header, and expansion GPIOs (PA3, PA4, PB13–PB15)[cite: 289, 290, 294].
